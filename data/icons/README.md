# Icons

## App icon

`../dev.gmux.Gmux.svg` adapts GNOME Console's app icon, designed by Tobias Bernard and GNOME Console contributors. The source is `data/org.gnome.Console.svg` at revision `dd2e5ed87eec404567d700cdf50181ee761d3847`.

Gmux's version, modified on 2026-10-03, adds split terminal panes and blue prompts, uses a flat front frame, and reduces the bottom profile to 4px. It follows the [GNOME app icon guidelines](https://developer.gnome.org/hig/guidelines/app-icons.html) with a 128×128 canvas, a 116px baseline, and details on a 2px grid. `../dev.gmux.Gmux-symbolic.svg` is a matching 16×16 drawing with a pane divider, prompt, and cursor.

The full-color app icon is licensed under GPL-3.0-or-later; see [COPYING.Console](COPYING.Console). The symbolic icon is original Gmux artwork under the project's MIT license.
