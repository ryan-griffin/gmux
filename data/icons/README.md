# Icon credits

`../dev.gmux.Gmux.svg` adapts GNOME Console's app icon by Tobias Bernard and
GNOME Console contributors, adding split panes and blue prompts. It is licensed
under GPL-3.0-or-later; see [COPYING.Console](COPYING.Console).

[Source artwork](https://github.com/GNOME/console/blob/dd2e5ed87eec404567d700cdf50181ee761d3847/data/org.gnome.Console.svg).
The matching symbolic app icon is original Gmux artwork under the project's
MIT license.

`branch-symbolic.svg` is the unmodified branch icon from GNOME's Icon Development
Kit under CC0 1.0; see [COPYING.md](COPYING.md).

[Source artwork](https://gitlab.gnome.org/Teams/Design/icon-development-kit/-/raw/e5857f6d796a96571a61030db40f35bfb8815a94/icons/branch.svg).

`laptop-symbolic.svg` is the unmodified laptop icon by Jakub Steiner from the
same GNOME Icon Development Kit revision, under CC0 1.0.

[Source artwork](https://gitlab.gnome.org/Teams/Design/icon-development-kit/-/raw/e5857f6d796a96571a61030db40f35bfb8815a94/icons/laptop.svg).

`chip-symbolic.svg`, `container-symbolic.svg`, and `server-symbolic.svg` are also
unmodified icons by Jakub Steiner from that GNOME Icon Development Kit revision,
under CC0 1.0. The server symbol uses the kit's `network-raid` artwork.

[Chip source artwork](https://gitlab.gnome.org/Teams/Design/icon-development-kit/-/raw/e5857f6d796a96571a61030db40f35bfb8815a94/icons/chip.svg).
[Container source artwork](https://gitlab.gnome.org/Teams/Design/icon-development-kit/-/raw/e5857f6d796a96571a61030db40f35bfb8815a94/icons/container.svg).
[Server source artwork](https://gitlab.gnome.org/Teams/Design/icon-development-kit/-/raw/e5857f6d796a96571a61030db40f35bfb8815a94/icons/network-raid.svg).
